STUDIO MANAGEMENT

Admin setup notes

This is a simple setup guide, not a secure admin login or database.

Update your studio details

  1. Open index.html and edit the contact section.
  2. Replace the sample gallery image URLs with your own public image links.
  3. Update the WhatsApp link with your correct country code and number.
  4. Upload the changed files to your GitHub repository.

Never place passwords, private customer photos, or API keys in this public repository.
